Como clonar e executar

Python Local Docker
# 1. Clone o repositório oficial da equipe
git clone https://github.com/Thiago-Navo/Pr--Trabalho-Trabalho-Final.git
cd Pr--Trabalho-Trabalho-Final

# 2. Crie e ative o ambiente virtual
python -m venv .venv
.venv\Scripts\activate # No Linux/macOS: source .venv/bin/activate

# 3. Instale as dependências e popule o banco
pip install -r requirements.txt
python seed.py

# 4. Inicie o sistema
python run.py
# Acesse: http://127.0.0.1:5001 (Login: admin / admin123)
