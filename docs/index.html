Sistema de gestão de estoque

Organize o controle de produtos, entradas e saídas com eficiência.

O TechStock é uma aplicação web para gestão de estoque de informática, com foco em controle de produtos, movimentações, categoria de itens e indicadores em tempo real.

Ver repositório

Resumo do projeto

Dashboard inteligente, autenticação por perfil, movimentações entre ruas, publicação de relatório e gestão de estoque em um único ambiente.

8+ categorias
100% local
1 dashboard

Funcionalidades principais

Cadastro de produtos

Registro de itens com SKU, categoria, estoque mínimo e máximo.

Controle de movimentações

Gerencia entradas, saídas e transferências entre ruas do estoque.

Dashboard

Indicadores visuais para facilitar análise do nível de estoque e movimentações.

Autenticação

Login com diferentes permissões e proteção de acesso por perfil.

Tecnologias

Python

Backend principal da aplicação.

Flask

Framework web para rotas, autenticação e regras de negócio.

SQLite

Banco relacional local para persistência dos dados.

Jinja2 + HTML

Renderização das telas e integração com templates.
