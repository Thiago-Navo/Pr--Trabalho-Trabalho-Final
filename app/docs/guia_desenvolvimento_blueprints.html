1 Rotas e Métodos HTTP (GET, POST, PUT, DELETE)

O protocolo HTTP define verbos para indicar o objetivo de cada requisição. Em aplicações web com formulários HTML padrão, GET e POST são os mais utilizados.

Método Objetivo Principal Origem Comum Como Ler Dados no Python
GET Consultar / Carregar página HTML ou dados sem alterar o servidor Barra de endereços, cliques em <a href>, buscas request.args.get('q')
POST Criar / Processar formulário de envio (inserir novo produto, login) Formulários <form method="post"> ou fetch() request.form.get('nome') ou request.get_json()
PUT / PATCH Atualizar dados existentes APIs AJAX com fetch() request.get_json()
DELETE Excluir um registro Formulários com POST ou APIs fetch() Parâmetro na URL ou request.form

Exemplos Práticos no TechStock

Exemplo 1: Rota GET com Filtro de Busca (Query Params) Python 
@front_bp.route("/produtos", methods=["GET"])
def produtos():
    # Captura ?q=Memoria da URL: /produtos?q=Memoria
    termo = request.args.get("q", "").strip()
    
    db = database.get_connection()
    if termo:
        produtos = db.execute(
            "SELECT * FROM produtos WHERE nome LIKE ? OR sku LIKE ?", 
            (f"%{termo}%", f"%{termo}%")
        ).fetchall()
    else:
        produtos = db.execute("SELECT * FROM produtos").fetchall()
        
    return render_template("produtos.html", produtos=produtos, termo=termo)
Exemplo 2: Rota POST para Salvar Formulário de Novo Produto Python 
@front_bp.route("/produtos/novo", methods=["POST"])
def novo_produto():
    # Pega os valores enviados pelo formulário HTML (atributos name="...")
    nome = request.form.get("nome")
    sku = request.form.get("sku")
    categoria_id = request.form.get("categoria_id")
    quantidade = request.form.get("quantidade", 0)
    
    db = database.get_connection()
    db.execute(
        "INSERT INTO produtos (nome, sku, categoria_id, quantidade) VALUES (?, ?, ?, ?)",
        (nome, sku, categoria_id, quantidade)
    )
    db.commit() # Não esqueça do commit ao alterar dados!

    flash("Produto cadastrado com sucesso!", "success")
    return redirect(url_for("front.produtos"))
Exemplo 3: Rota com Parâmetro Dinâmico de URL (<int:id>) Python 
@front_bp.route("/produtos/<int:produto_id>/excluir", methods=["POST"])
def excluir_produto(produto_id):
    db = database.get_connection()
    db.execute("DELETE FROM produtos WHERE id = ?", (produto_id,))
    db.commit()

    flash(f"Produto #{produto_id} excluído com sucesso!", "info")
    return redirect(url_for("front.produtos"))
2 Como Conectar e Chamar o Banco de Dados

O TechStock centraliza a conexão no módulo app.database.database. A conexão é aberta sob demanda por requisição e fechada automaticamente.

Padrão Oficial de Consultas SQL Python 
from app.database import database

def minha_funcao_back():
    # 1. Obtém a conexão ativa com o SQLite
    db = database.get_connection()

    # 2. SELECT retornando 1 registro (fetchone)
    total = db.execute("SELECT COUNT(*) AS total FROM produtos").fetchone()["total"]

    # 3. SELECT retornando múltiplos registros (fetchall)
    cursor = db.execute("SELECT id, nome, quantidade FROM produtos WHERE quantidade <= 5")
    itens_baixos = cursor.fetchall()  # cada item pode ser acessado como dicionário: item["nome"]

    # 4. INSERT / UPDATE / DELETE sempre parametrizados com (?) para evitar SQL Injection
    db.execute(
        "UPDATE produtos SET quantidade = ? WHERE id = ?", 
        (10, 1)
    )
    db.commit() # Salva a transação
⚠️ Regra de Segurança Crítica: SQL Injection
NUNCA concatene variáveis com strings formatadas (ex: f"SELECT ... WHERE id = {meu_id}"). Sempre utilize a interrogação ? e passe os parâmetros em uma tupla: db.execute("... WHERE id = ?", (meu_id,)).
3 Como o Back-End Alimenta o Front-End (Jinja2)

A função render_template(arquivo, **contexto) envia variáveis do Python para o HTML.

@front_bp.route("/dashboard")
def dashboard():
    total = 150
    usuario = "Thiago"

    ]

    return render_template(
        "dashboard.html",
